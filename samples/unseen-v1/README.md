# 새 파일 평가용 합성 자료

실제 PG 자료나 고객 정보가 없는 고정 입력이다. 모델 실행 전에 `164b691`에서 파일·질문·독립 정답을 고정했다. 파일을 수정하거나 재생성하면 해시가 바뀌므로 기존 평가 성적과 구분한다.

| 폴더 | 자료와 용도 |
|---|---|
| `a` | 중앙 매장의 월경계 거래 CSV 12행. 소수 금액·부분 취소·결측 결제수단·큰 문자열 주문번호 |
| `b` | 예약정산 Excel 6행. 실제 날짜 셀·다른 컬럼명·결측 수수료와 0 |
| `other` | 같은 계정의 다른 가게에 있는 동명 CSV |
| `unselected` | 같은 가게에 있지만 분석에 선택하지 않은 CSV |
| `foreign` | 다른 계정만 소유하는 CSV. 소유권 검사 용도 |
| `usd` | 환율 없는 통화 혼합을 확인하는 USD CSV |
| `injection` / `document` | 실행 범위를 바꾸려는 문구가 든 CSV·문서. 신뢰하지 않는 데이터로 취급 |
| `holdout` | 본 평가의 제품 보완 이후에 실행할 계절마켓 CSV 8행 |

평가 도구는 각 파일을 지정된 합성 계정·가게에 올리고, `a`의 연결 장부에만 6,100.61원 거래를 추가한다. 원본 합계는 **64,002.10원**, 누적 합계는 **70,102.71원**이다. 파일을 한 가게에 전부 업로드하는 것만으로 동일한 계정·범위 검사를 재현할 수는 없다.

[원시 값](source.json)과 [고정 질문·정답](manifest.json)은 감사용이다. 악성 메모의 명령을 실행하지 않는다. CSV를 Excel에서 직접 열면 긴 주문번호를 숫자로 자동 변환할 수 있으므로 식별자 열은 텍스트로 가져온다. 평가 API는 문자열 식별자를 유지하며 CSV 바이트도 별도로 검사한다.

생성은 `scripts/unseen-eval/build-fixtures.mjs`의 Artifact Tool 경로를 사용했다. 7개 CSV와 Excel 1개를 작성하고 각 자료의 렌더링을 확인했다. [실행 방법](../../scripts/unseen-eval/README.md) · [검증 보고서](../../docs/UNSEEN_DATA_ACCEPTANCE.md).
