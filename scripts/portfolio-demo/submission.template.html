문제와 해결

여러 가게·결제수단에 흩어진 매출 파일과 현금 기록을 모아, 질문으로 필요한 통계를 만든다. 파일 선택 → 도구 호출 → 구조화 지표 → SQL 집계 → 표·그래프 확인 → 저장·재계산까지 연결했다.

설명할 기술 판단 3가지

① 구조화된 실행 계약

LLM이 지표 정의를 제안하고 서버가 소유권·출처·집계 조건을 검증해 SQL을 구성한다. 임의 코드 실행보다 지원 범위는 좁지만 재계산 기준을 보존한다.

② 숫자와 설명의 분리 검증

도구 인자·필터·기간·Decimal 집계 셀·차트 개수와 유형을 검사한다. 정보 부족 응답은 별도 근거 검토로 판정한다.

③ 관측에서 회귀 사례로

실행 상태·사용량·평가를 기록하고 관리자가 실패 근거를 검토한다. 합성 후보와 독립 정답을 수동 준비해 평가에 편입한다.
