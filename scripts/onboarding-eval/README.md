# 첫 대시보드 실제 브라우저·모델 평가

루트에서 `python scripts/onboarding-eval/run.py`를 실행한다. 루프백 pgvector PostgreSQL의 관리 DSN을 `DATAEZ_RAG_TEST_DATABASE_URL`로 지정한다. Python API 의존성, `web/node_modules`, `scripts/ui-eval/node_modules`의 Playwright와 Edge가 필요하다. 모델 API 키는 환경 변수 또는 루트 `.env`에서 읽고 출력하지 않는다.

빈 계정으로 가게를 만들고 합성 결제 CSV를 연결한다. 금액 컬럼의 모호한 후보를 직접 선택하고, 잘못 지정한 양수 결제 해석을 취소 포함 부호 유지로 수정한다. 전체 합계 180,000원에서 중복 50,000원을 제외하여 130,000원을 반영한다.

브라우저 새로고침 후 업로드 이력을 통해 첫 지표 화면으로 이동한다. 일별 그래프를 매시간 갱신 지표로 저장하고 다시 접속해 확인한다. 출처가 담긴 자연어 질문 초안을 직접 전송해 실제 모델 미리보기를 확인한다. 두 번째 빈 가게로 전환한 뒤 기존 데이터·지표가 섞이지 않는지도 검사한다. API를 모킹하지 않는다.

매 실행은 새 격리 DB와 로컬 임시 API·웹 서버를 사용한다. 종료 시 생성한 DB·프로세스를 정리하고 일반 Next 빌드를 복원한다. 실행 중 다른 작업에서 같은 `web/.next`를 빌드하지 않는다.

`artifacts/`에는 계정 입력, 원시 대화·로그가 있어 Git에서 제외한다. 공개 기록은 검증 결과, 합성 질문·답변·사용량과 검토한 화면만 추린다. 실제 사용자 사용성이나 PG 파일럿을 대신하는 평가는 아니다.
