# DATA:EZ BI concept prompts

Generated on 2026-09-10 with the built-in image generation tool. The actual dark and light DATA:EZ dashboard captures were supplied as product-context references, not as edit targets.

Shared constraints for all three boards:

- One large 16:10 premium identity board per direction
- Exact wordmark: `DATA:EZ`
- Charcoal and blue palette derived from the current application
- Dark and light lockups, symbol construction, and 16/24/32 px icon checks
- Flat, minimal, vector-friendly forms compatible with Spoqa Han Sans Neo UI
- No database cylinder, generic AI sparkle, growth promise, watermark, or copied real-world logo

## A — Colon Bridge

Create an original symbol from two vertically aligned rounded blue dots and a subtle enclosing bridge. Treat the colon as the trusted handoff between scattered data and an understandable answer. Keep it calm and friendly, avoiding terminal-prompt or developer-tool associations. Show the exact same symbol in the wordmark, construction, dark/light lockups, and icon scale row.

## B — Gathered Ledger

Create an original symbol from three short staggered sales-record strips that align and resolve into one unified rounded dashboard frame, optionally using negative space to suggest an `E` or stable chart baseline. Avoid database, cube, folder, and generic bar-chart forms. Show scattered file records converging into one readable view.

## C — Question Path

Create an original monoline symbol in which two colon-like nodes are connected by a measured path that settles into a stable answer line inside an open rounded frame. It may faintly recall a question curve, but must not become a literal speech bubble, magnifier, sparkle, arrow, or chatbot. Show the path evolving from question to verified answer and saved chart.
