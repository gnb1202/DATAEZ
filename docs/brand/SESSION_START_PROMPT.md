DATA:EZ의 브랜드 아이덴티티(BI)와 대표 이미지를 구체화하려고 합니다. 첨부한 `BRAND_HANDOFF.md`를 먼저 읽어주세요. 같은 저장소에서 작업한다면 `D:/Github/DATAEZ/docs/brand/BRAND_HANDOFF.md`입니다.

DATA:EZ는 소상공인이 흩어진 CSV·엑셀 매출 파일을 모으고, 자연어로 통계와 그래프를 만들어 자기 대시보드에 저장하는 서비스입니다. 한 계정으로 여러 가게를 관리하며, 사용자가 선택한 파일과 계산 근거를 확인할 수 있습니다. 실제 앱과 지속형 로컬 데모는 구현되어 있고, 지금은 포트폴리오에 사용할 브랜드 표현을 다듬으려 합니다.

확정 사항은 **Charcoal + Blue, 다크 기본·라이트 지원, UI 폰트 Spoqa Han Sans Neo**입니다. 이름은 `DATA:EZ`를 기본 표기로 유지해주세요. 로고·심볼·슬로건·대표 이미지와 콜론의 브랜드 의미는 아직 미확정입니다.

먼저 서로 다른 BI 방향 **3개를 실제 이미지 시안으로** 보여주세요. 각 안에 간단한 콘셉트, 워드마크·심볼, 다크·라이트 적용, 작은 아이콘 적용을 담고, 차이를 읽을 수 있도록 안별 이미지를 충분한 크기로 분리해주세요. 추천하는 안 1개와 이유도 알려주세요. 문서의 A/B/C는 탐색 제안이므로 더 적절한 대안으로 발전시켜도 됩니다.

앱의 정확한 숫자와 정돈된 정보 구조에 어울리면서도, 소상공인이 접근하기 쉬운 인상을 원합니다. 제공된 화면은 기존 제품 맥락의 참고 자료입니다. 외부 PG 실시간 자동 연동, 결제 실행, 실제 고객 성과처럼 제공하지 않거나 검증하지 않은 기능·성과를 표현하지 마세요.

브랜드 작업에 맞는 이미지 생성 도구를 활용해주세요. 생성한 로고 이미지는 콘셉트 시안으로 구분하고, 최종 글자·간격·벡터 제작은 선택한 방향에서 정리합시다. 첫 비교 단계에서는 앱 코드나 확정 폰트·팔레트를 변경하지 말고, 제가 방향을 선택할 수 있는 결과부터 만들어주세요.
