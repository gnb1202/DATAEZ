# DATA:EZ 브랜드 결정 기록

## 2026-09-10 — BI 방향 선택

- 선택 방향: **B — Gathered Ledger**
- 핵심 은유: 흩어진 매출 기록이 정렬되어 하나의 읽기 쉬운 대시보드가 된다.
- 심볼 구조: 세 개의 장부 행 + 하나로 닫히는 둥근 대시보드 프레임
- 유지 인상: 정확함, 정돈됨, 차분함, 접근하기 쉬움
- 제외 표현: 성장 화살표, 데이터베이스 원통, 지갑·카드 결제 전용 인상, 로봇·스파클 중심의 AI 클리셰

당시 상태는 **선택 방향을 구체화한 작업안**으로, 제품 코드와 파비콘을 교체하기 전이었다. 이후 아래 2026-09-11 제품 적용·마스터 확정 기록으로 대체되었다.

## 2026-09-11 — 제품 적용

- 가로 로고와 독립 심볼을 공용 React 컴포넌트로 추가했다.
- 대시보드 사이드바의 `DATA:EZ` 텍스트와 접힘 상태의 `D:`를 Gathered Ledger 로고로 교체했다.
- 로그인 화면에 대표 카피 **“흩어진 매출을, 한눈에.”**와 파일 → 질문 → 검증·저장 흐름을 적용했다.
- 브라우저 제목을 `DATA:EZ` 표기로 통일하고 기존 막대그래프 파비콘을 독립 심볼로 교체했다.
- 다크·라이트 로그인, 다크·라이트 대시보드, 접힌 사이드바를 실제 브라우저에서 검증했다.

## 2026-09-11 — 마스터 자산과 공유 이미지

- Gathered Ledger 로고를 다크·라이트·흑백 가로 조합, 독립 심볼, 블루·차콜 앱 아이콘으로 정리했다.
- SVG 원본과 16–512px PNG 출력을 함께 제공하는 v1.0 마스터 패키지를 만들었다.
- 대표 카피 **“흩어진 매출을, 한눈에.”**를 사용하는 1200×630 링크 공유 이미지를 확정했다.
- Open Graph와 X/Twitter 메타데이터가 같은 공유 이미지를 사용하도록 제품에 연결했다.
- 16px 독립 심볼의 판독성과 모든 PNG의 크기·투명 배경을 검수 대상으로 삼는다.

로고 형태와 대표 카피는 v1.0 기준으로 고정한다. 상표 등록이나 대규모 매체 집행 전에는 상표 유사성 검토와 매체별 인쇄 감리를 별도로 진행한다.

## 2026-09-11 — 통합 마무리

- 로고 형태·팔레트를 유지하면서 소형 PNG 잘림과 빈 이미지 문제를 수정했다.
- 낮은 높이의 로그인 패널 여백, 모바일 한글 줄바꿈, 접힌 사이드바 정렬을 보완했다.
- 프로덕션 빌드와 다크·라이트·모바일 화면 검증을 통과했다.
- 실제 공개 도메인이 없어 `NEXT_PUBLIC_SITE_URL` 지정과 재빌드를 남은 배포 작업으로 기록했다.
- 변경은 별도 BI worktree에서 커밋하며 활성 브랜치의 작업은 보존한다.

검증 범위와 재현 방법은 [통합 검증 기록](BRAND_INTEGRATION.md)에 정리했다.
