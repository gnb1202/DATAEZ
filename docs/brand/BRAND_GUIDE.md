# DATA:EZ 미니 브랜드 가이드

버전 1.0 · 2026-09-11 · 선택 방향: **Gathered Ledger**

## 1. 브랜드 핵심

DATA:EZ는 소상공인이 흩어진 매출 파일을 모으고, 자연어로 필요한 통계와 그래프를 만들며, 검증한 결과를 자기 대시보드에 저장하는 서비스다.

브랜드가 전달해야 할 인상은 다음 네 단어로 정리한다.

- **명료함:** 숫자와 계산 근거가 한눈에 읽힌다.
- **신뢰:** 과장된 성장 약속보다 검증 가능한 결과를 보여준다.
- **정돈:** 여러 파일과 가게를 하나의 일관된 작업 흐름으로 모은다.
- **친근함:** 데이터 전문가가 아니어도 질문하고 이해할 수 있다.

## 2. 로고 개념

Gathered Ledger 심볼은 세 개의 가로 기록 행이 오른쪽의 둥근 프레임으로 모이는 형태다. 흩어진 원본 기록, 하나의 정돈된 대시보드, 이니셜 `D`를 한 실루엣에 겹친다.

심볼은 매출 상승이나 예측을 약속하지 않는다. 방향성 화살표 대신 안정된 수평 행을 사용해 **정확한 정리와 이해**를 표현한다.

## 3. 기본형과 배경 적용

| 상황 | 심볼 | 워드마크 | 권장 배경 |
|---|---|---|---|
| 다크 UI | Bright Blue `#82B4FF` | Cloud White `#F2F4F7` | `#121417`–`#22252A` |
| 라이트 UI | Trust Blue `#245BB5` | Ink `#20262F` | `#FFFFFF`–`#F5F7FA` |
| 블루 앱 아이콘 | White `#FFFFFF` | 사용하지 않음 | `#245BB5` |
| 단색 문서 | 100% Black 또는 White | 동일 | 충분한 명도 대비 확보 |

로고에 그림자, 외곽선, 금속 질감, 임의의 그라디언트를 넣지 않는다. 다크용과 라이트용 색을 서로 뒤바꾸지 않는다.

## 4. 여백과 최소 크기

- 보호 여백 `x`는 심볼 기본 획 두께와 같다.
- 심볼 사방에 최소 `1x`, 가로 조합 사방에 최소 `1.5x`를 확보한다.
- 독립 심볼 최소 크기: 디지털 `16px`, 인쇄 `5mm`.
- 가로 로고 최소 너비: 디지털 `120px`, 인쇄 `32mm`.
- 16–20px에서는 독립 심볼만 사용한다. 워드마크나 슬로건을 함께 축소하지 않는다.

## 5. 색상

| 토큰 | 값 | 역할 |
|---|---|---|
| Charcoal | `#191B1F` | 기본 작업 배경 |

| Panel | `#22252A` | 카드·패널 |
| Bright Blue | `#82B4FF` | 다크 배경의 로고·핵심 강조 |
| Trust Blue | `#245BB5` | 라이트 배경의 로고·주요 행동 |
| Action Blue | `#316AC4` | 다크 UI의 버튼 배경 |
| Cloud White | `#F2F4F7` | 다크 UI의 주요 텍스트 |
| Ink | `#20262F` | 라이트 UI의 주요 텍스트 |
| Canvas | `#F5F7FA` | 라이트 작업 배경 |

앰버·로즈·그린은 차트와 상태를 위한 기능색으로 유지한다. 기본 로고에 섞지 않는다.

## 6. 타이포그래피

- UI와 브랜드 문서: **Spoqa Han Sans Neo** 400·500·700
- 제목·핵심 숫자: 700
- 짧은 설명·버튼: 500
- 본문: 400
- SQL·코드 전용: JetBrains Mono

워드마크는 Spoqa Han Sans Neo Bold를 바탕으로 하되 콜론을 두 개의 정원으로 별도 조형한다. 금액과 표에서는 장식적인 자간보다 정렬과 판독성을 우선한다.

## 7. 대표 그래픽 문법

대표 이미지와 온보딩 그래픽은 다음 순서를 시각화한다.

`흩어진 기록 행 → 정렬 → 하나의 둥근 프레임 → 읽을 수 있는 숫자와 그래프`

- 얇은 선과 가로 데이터 행을 반복 요소로 사용한다.
- 여러 가게는 서로 다른 색이 아니라 같은 블루 계열의 위치·레이어 차이로 표현한다.
- 그래프는 급격한 우상향보다 실제 업무 화면처럼 중립적으로 표현한다.
- 데이터 카드가 모이는 방향은 사용자의 읽기 흐름에 맞추되 화살표를 직접 그리지 않는다.
- 사진을 사용한다면 과장된 성공 포즈보다 실제 매장과 장부를 다루는 차분한 순간을 선택한다.

## 8. 카피 톤

짧고 구체적으로 쓰며, 사용자가 하는 행동과 확인 가능한 결과를 말한다.

대표 카피 제안: **“흩어진 매출을, 한눈에.”**

보조 설명: **“파일을 모으고, 대화로 지표를 만들고, 내 대시보드에 저장하세요.”**

권장 표현:

- “선택한 파일에서 계산했어요.”
- “계산 기준과 출처를 확인할 수 있어요.”
- “가게별로 나누어 보거나, 선택한 가게를 함께 비교하세요.”

피해야 할 표현:

- “100% 정확한 AI”
- “모든 매출을 자동으로 실시간 수집”
- “매출 성장을 보장”
- 확인하지 않은 고객 수·절감 시간·성과 수치
