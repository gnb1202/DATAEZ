# DATA:EZ 컬러 팔레트 — 차콜 + 블루 확정

상태: 2026-09-09 사용자 확정. [금융·매출 플랫폼 레퍼런스](PALETTE_REFERENCES.md)의 A안인 차콜 + 블루를 선택했다. 시안의 공통 토큰, 작업 공간, 차트, 글꼴 비교실과 팔레트 화면에 반영했다. 실제 Next.js 앱에도 통합했고, 2026-09-13에는 확정 팔레트 안에서 버튼·선택 상태·카드·그래프를 소폭 보정해 공개 웹에 배포했다.

## 1. 확정한 방향

- 차콜·중립 회색 바탕에 블루를 강조색으로 사용한다. 글꼴은 Spoqa Han Sans Neo다.
- 다크가 기본이며 라이트·시스템 설정을 함께 지원한다. 라이트에서는 밝은 회색 바탕·흰 패널 위에 짙은 블루를 사용한다.
- 주요 버튼은 블루 배경과 흰 글자다. 큰 금액은 기본 텍스트색으로 읽기 쉽게 표시한다.
- 기본 데이터 색 순서는 블루·앰버·로즈 등이다. 현재 ECharts는 계열/항목 순서에 팔레트를 적용하며, 현금은 항상 앰버·취소는 항상 로즈로 자동 매핑하는 기능은 아니다. 데이터의 의미는 범례와 라벨로 확인한다.
- 분석 가능 상태는 그린이다. 정상·검토 필요·보관 중·오류는 색과 라벨을 함께 사용하며, 취소 거래 자체를 오류로 취급하지 않는다.
- 색 이름 대신 역할을 나타내는 차트 토큰으로 관리한다.

## 3. 초기 시안의 테마 동작

- 저장된 설정이 없는 첫 방문은 운영체제 밝기와 관계없이 다크로 시작한다.
- 상단에서 다크·라이트·시스템을 선택한다. 명시적인 다크·라이트 선택이 운영체제보다 우선하며, 시스템 선택 시 운영체제 변경을 따른다.
- 선택은 시안의 브라우저 저장소에 보관한다. 저장소가 차단되어도 현재 페이지에서 전환할 수 있다.
- CSS 표시 전에 테마를 결정해 초기 화면의 밝기가 뒤늦게 바뀌는 것을 줄인다.
- 테마를 바꿔도 데이터 범위·차트 종류·금액·채팅 내용·현재 시안의 저장 상태를 유지한다.
- 차트 선·막대·도넛·축·범례·영역 채움·툴팁, 파일 목록, 상태 배지와 상세 대화상자를 함께 전환한다.
