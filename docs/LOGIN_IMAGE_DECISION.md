- 사진: 카페 사장님이 카운터 위 POS 모니터를 확인하는 장면.
- 원본: `output/imagegen/login-owner-pos-v2.png` (내장 이미지 생성 도구로 제작).
- 서비스 파일: `web/public/brand/login-owner-pos.webp`.

- 상하 명암 그라데이션으로 로고와 하단 문구의 가독성을 보완한다.
- 이미지 패널은 다크·라이트 모드에서 동일한 저채도 사진을 사용한다.
- 사진을 가리지 않도록 기존 단계 목록 대신 하단 핵심 문구를 배치한다.
- 모바일은 기존과 같이 이미지 패널을 숨기고 로그인 폼을 우선한다.
- 비교 도구: `output/imagegen/compare.html`.

- 최종 사진 카피: ‘우리 가게 매출, 한눈에.’ / ‘매출 파일을 모으고, 궁금한 것을 물어보세요. 내 가게에 필요한 통계가 대시보드로 완성됩니다.’
- 로그인 제목: ‘내 가게의 숫자를 만나보세요’. 기존 ‘다시 만나 반가워요’를 대체한다.
- 회원가입 제목: ‘우리 가게 매출, 여기서 시작해요’.
