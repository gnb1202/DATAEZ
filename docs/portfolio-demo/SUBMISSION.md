## 이력서용 설명

여러 가게의 매출 파일을 자연어로 분석하고 지표를 저장·재계산하는 DATA:EZ를 고도화했습니다. LLM의 구조화 도구 호출을 서버의 소유권·출처 검증과 SQL 집계로 연결하고, 독립 Decimal 기대값을 사용하는 24문항 평가 및 대화 품질 관측을 구성했습니다. 같은 개발 회귀셋에서 프롬프트 수정 전 22/24, 수정 후 24/24를 확인했습니다. 설명 6문항은 Codex의 근거 검토이며 일반 정확도나 독립 블라인드 평가를 뜻하지 않습니다.

## 직무별 강조

- **LLM 서비스 개발:** 파일 보관·선택부터 스트리밍 응답, 결과 검토, 저장·재접속까지 연결한 제품 흐름과 실패 복구.
- **LLM 오케스트레이션:** 도구 선택과 구조화 인자, 범위 가드, 정적/재계산 차트 지침 충돌, 도구 성공과 요구 충족의 분리 검증. 멀티에이전트 분산 실행 경험으로 확대하지 않기.
- **백엔드:** 사용자·가게·출처 격리, 정확한 금액 집계, 저장 재시도, 서버리스의 공유 DB 요청 제한과 작업 상태, 관측 권한과 보관 한계.

## 3분 설명 순서

1. 30초: 누구의 어떤 문제를 해결하는지, 공개 데모와 화면.
2. 60초: 구조화 지표 → 검증 → SQL → 표/그래프 → 재계산의 책임 분리.
3. 60초: 실제 지침 충돌 사례와 24문항 평가, 대화 관측에서 합성 회귀 후보로 이어지는 흐름.
4. 30초: 지원하지 않는 기능, 검사 범위, 자신의 결정과 AI 도구 활용 범위.

제품 소유자는 요구·범위·디자인·운영 우선순위를 결정했고 Codex와 구현·검증·배포·자료 제작을 진행했습니다. 단독 작성이나 직접 수행하지 않은 작업을 자신의 성과로 바꾸지 말고, 본인이 결정하고 검토한 부분을 설명하세요.
