### 후속 작업

- Phase 1: 이 두 가게와 고정 기대값에 맞춰 질문·장면·자막·예상 결과를 대본으로 확정.

- 실제 LLM 분석·저장·추가 거래 재계산·녹화·편집은 이 단계에서 실행하지 않았다.
- 계정과 모든 준비 자료를 다음 단계용으로 보존했다. 기존 사용자 데이터는 변경하지 않았다.

## Phase 2 — 공개 서비스 리허설 완료 (2026-09-12)

[실제 실행 기록](phase-2-rehearsal.json) · [다크 화면](assets/phase-2-dashboard-dark.png) · [라이트 화면](assets/phase-2-dashboard-light.png) · [원본 집계표·SQL](assets/phase-2-Q1-sql.png)

수정본에서 새 가게를 사용한 리허설 **2회 연속**을 통과했다. API 응답·모델 결과 mock 없이 실제 Vercel 웹/API와 Supabase 데이터를 사용했다. 각 take에서 질문 2회, 미리보기 후 저장 2회, 합성 거래 1회 추가, 원본·누적 재계산, 실제 마우스 드래그, 재접속·가게 전환을 확인했다.

| 최종 take | Q1 원본 응답 | Q2 누적 응답 | 거래 추가 후 집계표 합계 |
|---|---:|---:|---|
| 1 | 9.43초 | 8.66초 | 원본 690,200원 / 누적 720,200원 |
| 2 | 9.36초 | 9.07초 | 원본 690,200원 / 누적 720,200원 |

시간은 전송부터 응답 완료까지의 이번 관측값이며 성능 보장이나 영상 길이가 아니다. 토큰 사용량은 영속 메시지 API가 제공하지 않아 `null`(미확인)로 남겼다. 비용·토큰을 0으로 해석하지 않는다.

### 확인 내용과 수정

- 위젯이 있으면 차트를 안내보다 먼저 표시한다. 시작 안내·샘플 체험·직접 지표 만들기는 아래에서 펼칠 수 있다. 빈 대시보드 안내는 유지한다.
- 원본/누적 일별 금액, 음수 취소 포함, KRW, 전체 기간, 재계산 정의, 실제 SQL·집계표, 수동 저장을 검증했다. 원본 파일 SHA-256도 거래 추가 후 동일하다.
- 두 차트는 1920×1080에서 상단 262px~하단 778px에 함께 표시된다. 실제 드래그한 배치는 재접속·가게 전환 후에도 유지됐다. 각 최종 take의 브라우저 오류는 0건이다.
- 초기 시도에서 AI가 정적 차트를 함께 만들었고, 검사 도구가 동일 이름의 저장 버튼 2개 때문에 중단됐다. 도구가 재계산 결과 카드를 식별하도록 보완했다.
- 이후 요청한 선그래프가 저장 지표에는 막대로, 정적 차트에만 선으로 반영된 사례를 확인했다. 일반 그래프와 재계산 지표의 시스템 지침 충돌을 수정하고 `preview_metric` 정의에 모양·날짜 단위를 반영하도록 했다. 수정 후 두 번 모두 `preview_metric`의 선그래프 하나만 반환했다.
- 전체 5개 시도에서 실제 질문 8회를 실행했다. 실패·수정 전 성공 기록도 보존하며 최종 2회만 수정본의 완료 근거로 채택한다. 모델 출력의 확률적 변동이 영구히 없어졌다는 주장은 하지 않는다.
- 이 시연은 파일을 명시해 `library_references` → `preview_metric`으로 실행됐다. RAG 검색 호출이나 실제 PG 수집을 시연한 것으로 설명하지 않는다.

리허설 도구는 사용한 take의 재실행을 거부하고 append 전에 상태를 기록한다. 중단된 append를 자동 재시도하지 않는다. 원본·완료 가게는 모두 보존하고 다음 촬영용 가게는 8행·위젯 0개로 새로 준비했다. 최신 정보는 로컬 `account.json`과 `baseline-latest.json`에 있다. 최초 Phase 0 증거는 덮어쓰지 않는다.

공개 증거 스크린샷 6장은 캡처 시 계정 이메일 영역만 가렸다. 그래프와 계산 결과를 합성·수정하지 않았다. 영상·SRT는 다음 Phase의 작업이다.

파일은 로컬 `output/portfolio-demo/`에 있다. 대용량 마스터·중간 파일은 Git에서 제외하고, 제작 도구·자막·검증 자료·대표 화면은 저장소에 남긴다. 이번 단계에서 영상 공개 호스팅이나 앱 배포는 하지 않았다. 녹화본은 VP8 25fps이며 출력 30fps는 프레임률 변환이다. 무음 시청을 위한 자막형이고 음성 녹음은 없다.

계정 로그인은 녹화에서 제외하고 계정 표시만 숨겼다. 실제 결과의 합성·수정 없이 커서 강조·부분 확대·읽기용 정지·일부 조작 구간 속도 조정을 적용했다. 구조 설명은 실제 UI와 구분한다. 실패 또는 성공 이전 화면을 성공 동작으로 대체하지 않았다.
