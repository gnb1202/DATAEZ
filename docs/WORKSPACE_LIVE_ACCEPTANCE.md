# 파일·채팅·대시보드 실제 통합 검증

2026-09-10. 최신 실행에서 **자연어 질문 6개, 확인 항목 29개**를 통과했다. 브라우저 10개 흐름과 서버·DB 19개 확인 항목이다. 실제 브라우저 → HTTP API → 설정된 LLM → PostgreSQL을 연결했으며 응답을 모의 생성하지 않았다.

## 확인한 흐름

| 흐름 | 결과 |
|---|---|
| 로그인 → 파일 업로드 → 검사 → 분석 연결 | 소수 금액을 정확하게 보관하고 장부를 한 번 생성 |
| 자연어 파일 검색 → 보관함 선택 | 사용자가 실제 파일 후보에서 가게·누적 장부 범위를 확인 |
| 자연어 분석 → 실행 SQL·그래프 | 날짜별 원화 합계, 음수 취소 유지, 재계산 가능한 지표 정의 |
| 저장 전 설정 → 저장 → 배치 변경 | 원화·시간당 갱신을 확인하고 지표 한 개 저장, 크기 조절 |
| 추가 거래 → 수동·자동 재계산 | 공개 API로 추가한 거래가 실제 서버 계산에 반영 |
| API 재시작 → 새 브라우저 | 결과·정의·배치·저장 키·갱신 주기·다음 계산 시각 유지 |
| 후속 질문·다른 가게 선택 | 최신 누적 장부와 명시적으로 선택한 다른 가게만 각각 조회 |
| 파일 원본 범위 → 저장·재계산·재접속 | 추가 거래를 제외한 원본 행과 수정한 제목·원화 단위 유지 |
| 샘플 시작 → 첫 대시보드 | 별도 가게, 원본 선택·질문 초안, 실제 LLM 그래프, 이름·24시간 갱신을 확인하고 저장 |
| 계정 분리 | 다른 실제 테스트 계정의 파일 다운로드·위젯 목록 요청은 HTTP 404 |

## 금액 대조

원본은 4행이며 음수 취소를 그대로 차감한다.

| 계산 대상 | 9월 1일 | 9월 2일 | 9월 3일 | 합계 |
|---|---:|---:|---:|---:|
| 최초 장부 | 100,000.01 | 150,000.02 | 80,000.03 | 330,000.06 |
| 25,000.04 추가 후 수동 재계산 | 100,000.01 | 175,000.06 | 80,000.03 | 355,000.10 |
| 5,000.05 추가 후 자동 갱신 | 100,000.01 | 175,000.06 | 85,000.08 | 360,000.15 |
| 이후 파일 원본만 분석·저장·재계산 | 100,000.01 | 150,000.02 | 80,000.03 | 330,000.06 |

미선택 장부의 **999,999.99원**은 포함되지 않았다. 선택한 연남점 파일은 **54,321.09원**이었다. 별도 샘플 가게의 원본 8행은 **690,200원**이고 다른 가게의 거래·위젯에 섞이지 않았다.

원본 다운로드는 업로드 바이트와 동일했다. 누적 장부는 6행으로 늘었지만 원본 분석 자료는 4행을 유지했다. 요청한 누적 지표와 원본 지표를 각각 한 개 저장했고, 별도 샘플 가게에는 첫 지표 한 개를 저장했다.

## 자동 갱신과 실행 환경

모든 테스트 브라우저를 닫고 위젯 하나의 `next_refresh_at`만 과거로 옮겨 실제 **15초 주기의 서버 스케줄러**를 실행했다. 한 시간이 실제로 경과한 시험은 아니다. 공개 API로 거래를 추가했으며 계산 함수·결과를 대체하지 않았다. 갱신에는 LLM을 호출하지 않는다.

최종 실행은 `dataez_workspace_live_8f227a173631429085f4004481598d42`다. 직전 실행은 Windows의 PostgreSQL 연결 프로세스 생성 실패(error 1455)로 멈췄다. 테스트의 반복 DB 연결을 공개 API의 기존 풀 사용으로 바꾸고 풀 크기를 제한한 뒤 전체를 다시 실행했다.

실행별 테스트 DB·API·브라우저를 정리했고 기본 프론트 빌드를 복구했다. 모델 키·인증 세션은 공개 결과에 포함하지 않았다. 원본 로그와 테스트 세션은 Git에서 제외된 `scripts/ui-eval/artifacts/workspace-live/`에 보관한다.

## 재현

로컬 PostgreSQL의 테스트 DB 생성 권한, 설정된 모델 키, 프로젝트 Python/Node 의존성이 필요하다. 동일 체크아웃의 Next.js 서버는 먼저 종료한다.

```powershell
$env:PYTHONUTF8='1'
$env:DATAEZ_TEST_DATABASE_URL='postgresql://dataez_test@127.0.0.1:55439/postgres?connect_timeout=5'
python scripts/ui-eval/workspace-live.py --live-llm
```

`--live-llm`은 실제 유료 모델 호출을 사용한다. 키는 `.env` 또는 환경변수에서 읽는다. 테스트 종료 후 기본 빌드는 복구하지만 일반 개발 서버 재시작은 별도다.

이번 검증은 합성 CSV 경로다. PDF 임베딩 검색, Supabase 원격 저장, 실제 PG 파일과 결제 연동은 포함하지 않았다. 모든 자연어 표현의 정확도를 평가한 시험은 아니다.
