# Phase 3 — 새 파일·자연어 질문 평가

2026-09-11 · `codex/unseen-data-evaluation` · 평가 준비 완료, 실제 모델 본 평가 예정.

Phase 2 사용자 관찰은 대기로 유지한다. 이번 단계는 별도 작업 폴더의 실제 API·PostgreSQL·LLM 평가이며 브라우저 사용성 검사와 구분한다.

## 실행 전 고정한 기준

- 본 평가 30문항: 정상 분석 12, 모호함·부족한 자료 6, 후속 질문·저장/수정 6, 데이터·계정·파일 경계 6.
- 별도 질문 10개: 본 평가의 결함 보완을 마친 뒤 실행하며, 이 질문의 결과를 보완에 사용하면 더 이상 별도 미사용 평가로 보고하지 않는다.
- 목표: 본 평가 **27/30 이상**, 별도 평가 **9/10 이상**. 원본 SQL 금액·건수는 정확히 일치해야 한다.
- 계정 경계 침범, 선택하지 않은 자료 집계, 원본 거래 변경, 요청하지 않은 저장본 변경은 **0건**. 전체 점수와 관계없이 실패 처리한다.
- 설명을 검토하기 전에는 자동 점수를 최종 점수로 표시하지 않는다. 실패나 채점기 오류를 숨기거나 목표를 결과에 맞춰 낮추지 않는다.

## 자료와 독립 정답

[원시 합성 입력](../samples/unseen-v1/source.json), [고정 질문·정답·채점 규칙](../samples/unseen-v1/manifest.json), [실행 방법](../scripts/unseen-eval/README.md).

다른 컬럼명·순서, Excel 날짜, 소수 금액, 음수·부분 취소, 월 경계, 큰 문자열 주문번호, 결측 수단·수수료, 0, 동명 파일과 여러 가게, USD, 파일·문서 안의 지시문을 포함한다. 원본과 누적 장부의 차이는 실제 추가 거래로 만든다.

앱의 집계기나 SQL 컴파일러를 사용하지 않는 Decimal 정답 계산을 두고, 이를 실제 SQL 결과와 비교한다. 원본 월경계 합계 **64,002.10원**, 누적 추가 후 **70,102.71원**, 예약정산 Excel 합계 **16,211.63원**, 별도 계절마켓 합계 **7,701.40원**을 고정 대조값으로 검사했다.

## 현재 검증 상태

독립 정답·질문 고정·CSV 식별자·채점기 구분 검사 4개 통과. 실제 업로드·해석·SQL·매핑·권한의 준비 검증도 완료했다. 본 평가의 모델 응답과 설명 검토 결과는 실행 후 별도로 기록한다.
